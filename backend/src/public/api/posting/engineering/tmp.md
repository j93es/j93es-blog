안녕하십니까? 

구글 서치 콘솔의 알림/업적 기능과 관련하여 이슈가 추정되어 의견 올립니다.

아래 스크린샷은 j93.es 도메인에 대한 2025년도 알림을 캡쳐한 것입니다. 26년도 8월에 새로운 계정에 도메인을 등록하였으나, 과거 계정에서의 알림이 표출된 상황입니다.  더하여 업적 또한 동일한 현상이 발생합니다.

즉, 구글 계정 탈퇴 후, 새로운 구글 계정으로 도메인을 구글 서치 콘솔에 등록 시에, 이전 구글 계정에서의 알림/업적 항목이 그대로 표출됩니다.

다른 정보(ex. 등록된 링크) 등은 전부 초기화된 상태지만, 알림/업적에 대한 정보는 그대로 DB에 남아있는 것으로 판단됩니다. 즉, 계정 삭제 시에 알림/업적에 대한 정보의 삭제가 정상적으로 이루어지지 않아, 불필요한 DB 용량을 차지하고 있을지도 모르겠습니다.

더하여 저의 경우에는 소유권이 변경되지 않은 도메인이었습니다. 그런데 만약 소유권이 변경되었을 때에도 알림이 소유권이 이전된 사용자에게 전달된다면, 정보 유출의 이슈도 있어보입니다.

즉, 구글 계정 삭제 시에 알림 데이터를 제거한다면, 불필요한 DB 용량을 줄일 수 있고, 정보 유출의 위험도 낮아진다고 판단합니다.
